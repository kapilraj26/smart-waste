# SmartWaste AI

AI-powered smart waste classification, reporting, and collection management system.

## Structure

- `frontend/` — React.js + Vite frontend
- `backend/` — FastAPI backend
- `ai-model/` — AI model development (training / evaluation)
- `database/` — SQL schema and seed data
- `docs/` — Requirements, architecture, API documentation
- `tests/` — End-to-end / integration tests

## Quick Start

See `frontend/.env.example` and `backend/.env.example` for required environment variables.

```bash
docker-compose up --build
```
